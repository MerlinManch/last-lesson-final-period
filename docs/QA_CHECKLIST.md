# QA-Checkliste

- [ ] Neuer Spielstand führt zur Charaktererstellung
- [ ] Name blockiert URLs, E-Mail-ähnliche Angaben und sehr lange Zahlenfolgen
- [ ] Story-Level 1 startet mit Tastatur und Touch
- [ ] Checkpoint aktiviert und speichert Resume-Position
- [ ] Tod behält eingesammelte Run-Gegenstände
- [ ] Bosslevel sperrt Krankenzimmer während aktivem Boss
- [ ] Levelabschluss vergibt Note, Währungen und Freischaltungen
- [ ] Doppelte Reward-Transaktion wird verhindert
- [ ] Wallet wird nicht negativ
- [ ] Lootchancen zeigen 100 %
- [ ] Episch-/Legendär-Pity wird zurückgesetzt
- [ ] Daily Reward kann nur einmal pro Tag abgeholt werden
- [ ] Endlosmodus endet bei einem Treffer und zeigt Revive-Zahl
- [ ] Querformat auf 16:9, 19.5:9, 20:9 und Tablet prüfen
- [ ] Screen Shake, reduzierte Bewegung und Touchskalierung prüfen
- [ ] Offline-Neuladen nach erstem Onlinebesuch prüfen
- [ ] Safari iOS und Chrome Android auf echten Geräten prüfen
